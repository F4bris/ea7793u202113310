# TrailQuest Adventure Camp

## Overview

Web application for Adventure camps to manage reservations, check the current weather
and monitor the capacity of each adventure camps.

- ## Features

- Toolbar with custom logo, platform title and EN/ES language switcher.
- Sidenav with "Home" and "New Reservation".
- Home: "My Adventure Camps" grid with one summary card per center
- New Reservation: reactive form with validation. The weather temperature is
  retrieved automatically from Open-Meteo for the selected sports center.
